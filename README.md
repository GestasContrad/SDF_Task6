The authorization process begins when the user sends their credentials (login and password) through the client application to the server. The web server then accesses the database to find the user and verify the entered password against the one stored in the system. If successful, the server generates a unique access token (or session) and returns it to the user for further use. However, if the credentials are incorrect, the server rejects the request and returns a 401 status code with an error message, denying access to the system.
